Introduction

In this lesson you will learn to add ~별 to nouns and what it means. It often attaches to a noun to describe another noun, or combines with ~로 to act as an adverb.

1

To be Grouped or Classified by:~별(로)

~별 is added to nouns that represent more than one type or level of something. It classifies the different types or levels and indicates that something is done (separately) for each one. For example:

수준
level

수준별: There could be multiple levels of something (for example, high, medium, low). Something will be done separately for each level.

성
sex/gender

성별: There is more than one sex/gender. The sexes are classified and something is done separately for each.

학년
a grade level in school (1st grade, for example)

학년별: Grades within a school are classified and something is done separately for each grade.

부서
department

부서별: Departments within a company or office are classified and something is done separately for each department.

개인
personal, individual

개인별: Individuals are classified and something is done separately for each person.

국가
nation

국가별: Nations are classified and something is done separately for each nation.

These constructions (which count as nouns) are often placed before other nouns to describe them. For example:

수준별 수업
a class divided by levels
성별 임금 차이
the difference in wage between the two sexes
학년별 명단
a list of students names based on grade
부서별 회의
a meeting for each department
개인별 평가
an evaluation done for each individual
국가별 언어 설정
the language setting for each nation

These can now go into sentences. For example:

수준별 수업은 좋은 점도 있고 나쁜 점도 있어요
Classes divided by levels have good points and bad points, too
대부분 회사에는 성별 임금 차이가 있어요
At most companies, there is a wage difference between sexes
개학 전에 우리는 학년별 명단을 작성해야 돼요
Before the start of school, we need to make a list of students names by grade
각 부서마다 부서별 회의를 할 거예요
Each department will have a meeting (among themselves)
연말이라서 부서별 회식이 많아요
It is the end of the year, so there are a lot of staff dinners/parties among departments
12월까지 우리 회사는 개인별 평가를 시행하겠습니다
Until December, our company will be running a personal evaluation
새로운 컴퓨터를 사면 국가별 언어 설정을 해야 돼요
When you buy a new computer, you need to set the language setting (appropriate for your nation)

There are many possible translations for ~별(로). As the examples below show, it might translate to:
