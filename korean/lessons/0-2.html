Unit 0: Hangul · Lesson 0.2

More Basic Korean Letters

In the previous lesson you learned the most basic letters of the Korean alphabet. There are a few more to learn before we go further. Since you already know how syllables are built, the rest is just more letters.

The first new letter is confusing at first, but you need to memorize it before moving on. The letter is: ㅇ
In the previous lesson you learned that Korean syllables are always written in one of these ways:

You also learned that position 2 is ALWAYS a vowel and the other positions are always consonants.

So position 1 is always a consonant (and position 3 too, if there is one). But does that mean every syllable must start with a consonant sound?

The answer: Sort of.

When ‘ㅇ’ sits in position 1 it is silent, and the first sound you hear is the vowel in position 2. Some examples:

안
an
운
un
온
on
업
eob

This silent letter lets us keep the rule “position 2 is ALWAYS a vowel”.

What makes the letter ‘o’ trickier is that it has a different sound in position 3. There it sounds like the ‘ng’ in “walkiNG”. Some examples:

강
kang
방
bang
깅
king
공
kong

The letter ㅇ can appear in both position 1 and position 3:

앙
ang

There are a few more letters to learn. Each one looks and sounds very similar to a letter you already know. That makes them easy to learn, but hard for English speakers to tell apart.

Here they are in sets:
ㄱ set
ㄱ is the letter you already learned (k)
ㄲ is a new letter. It is two ㄱ’s side by side. It sounds very similar to ‘ㄱ’ but is more forced at the start of the pronunciation. It is Romanized as ‘kk’
ㅋ is also a new letter. It also sounds very similar to ‘ㄱ’ and is Romanized as ‘k’

ㅂ set
ㅂ is the letter you already learned (b)
ㅃ is a new letter. It is two ㅂ’s side by side. It sounds very similar to ‘ㅂ’ but is more forced at the start of the pronunciation. It is Romanized as ‘bb’
ㅍ is also a new letter. It sounds very similar to ‘ㅂ’ but is Romanized as ‘p.’ It is closer to an English ‘p’, but even in English B and P are VERY similar (say box and pox and try to tell them apart)

ㅈ set
ㅈ is the letter you already learned (j)
ㅉ is a new letter. It is two ㅈ’s side by side. It sounds very similar to ‘ㅈ’ but is more forced at the start of the pronunciation. It is Romanized as ‘jj’
ㅊ is also a new letter. It sounds very similar to ‘ㅈ’ but is Romanized as ‘ch.’ It is closer to an English ‘ch’, but even in English J and CH are VERY similar (say char and jar and try to tell them apart)

ㄷ set
ㄷ is the letter you already learned (d)
ㄸ is a new letter. It is two ㄷ’s side by side. It sounds very similar to ‘ㄷ’ but is more forced at the start of the pronunciation. It is Romanized as ‘dd’
ㅌ is also a new letter. It sounds very similar to ‘ㄷ’ but is Romanized as ‘t’. It is closer to an English ‘t’, but even in English T and D are VERY similar (say task and dask and try to tell them apart)

ㅅ set
ㅅ is the letter you already learned (s)
ㅆ is a new letter. It is two ㅅ’s side by side. It sounds very similar to ‘ㅅ’ but is more forced at the start of the pronunciation. It is Romanized as ‘ss’

In one way these new letters are simple, because they build on letters you already know. In another way they add confusion, because they sound so much like the old ones.

All of the new letters form syllables just like the letters from Lesson 1. For example:

ㄸ

ㅏ
a
ㅇ
ng

ㅏ is vertical, so a syllable with it looks like: 땅 (ddang)

ㅌ
t
ㅗ
o
ㅇ
ng

ㅗ is horizontal, so a syllable with it looks like: 통

Even after years of Korean, it is hard to hear the difference between ㄱ, ㄲ and ㅋ; ㅈ, ㅉ and ㅊ; ㅂ, ㅃ and ㅍ; ㄷ, ㄸ and ㅌ; and ㅅ and ㅆ. If you know a Korean speaker, ask them to use these letters in words so you can practice telling them apart. It is not easy, and it is not essential right now.

For example, try to hear the difference between these three letters:

ㄱ
ㄲ
ㅋ

“ㄲ” is fairly easy to pick out, but ㄱ and ㅋ sound essentially the same.
