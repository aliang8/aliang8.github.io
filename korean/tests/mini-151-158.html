Lessons 151 to 158 Mini-Test

All finished Lessons 151– 158? Now it is time to test yourself on what you learned in those lessons! Before moving on to the next set of lessons, make sure you can understand all the concepts covered here. Good luck!

The answers are at the bottom of the test!

1) Which 의성어 fits best in this sentence:

창밖에서 빗물이 __________ 흘러내렸어요

a) 따르릉
b) 냠냠
c) 킥킥
d) 주르륵

2) Which 의태어 fits best in this sentence?

아침에 냉장고를 열어 보니 냉장고 안이 _________ 비어 있었어요

a) 졸졸
b) 빙빙
c) 텅텅
d) 꽁꽁

3) Which of the following words/constructions fits best in the following sentence:

비가 ___________ 실외 활동보다 실내 활동이 나아요

a) 오는 경우에는
b) 위주로
c) 오려던 참에
d) 덜커덕 와서

4) Which of the following words/constructions fits best in the following sentence:

이 식당은 채식 메뉴 _________ 음식을 제공해요

a) 준비하려니까
b) 위주로
c) 준비할 경우
d) 먹으려다가

5) Choose the best ending to the following sentence:

운동을 하려니까 ______________

a) 열심히 했어요
b) 비가 갑자기 오기 시작했어요
c) 친구랑 같이 했어요
d) 헬스장에 안갔어요

6) Choose the best way to start this sentence:

_____________ 친구한테서 전화가 와서 잠깐 이야기했어요

a) 청소할 경우에는
b) 청소 위주로
c) 청소를 하려다가
d) 청소를 싹 했지만

7) Which of the following could you replace the underlined part of the sentence with to create a similar meaning:

점심을 먹으려는 참에 친구가 같이 먹자고 연락했어요

a) 먹으려니까
b) 먹으려다가
c) 먹을 경우
d) 먹어서

8) Choose the correct word or construction to put into the blank below:

방금 사고를 당한 사람을 도와주려는 ________________ 모두 방법을 몰라서 망설였어요

a) 사람 차근차근 도와서
b) 사람이 없을 경우
c) 사람 위주로
d) 사람이 많았지만

Show answers

1) d
2) c
3) a
4) b
5) b
6) c
7) a
8) d
